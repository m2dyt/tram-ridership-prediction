# frontend/src/pages — страницы веб-интерфейса

В данной директории содержатся сборные экраны пользовательского интерфейса оператора:

---

## Файлы

| Файл                                   | Назначение                                                                                                                      |
| -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| [DashboardPage.jsx](DashboardPage.jsx) | Главный операционный дашборд: сводка по маршрутной сети, свежесть данных, параметры и графики прогноза.                         |
| [MapPage.jsx](MapPage.jsx)             | Географический экран: интерактивная карта сети Leaflet, трамвайные линии, остановки, визуализация расчетной загрузки перегонов. |
| [ModelsPage.jsx](ModelsPage.jsx)       | Экран аудита моделей: мониторинг доступных бандлов, метрики WAPE/MAE и переключение активной модели.                            |
