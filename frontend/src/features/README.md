# Экраны приложения

Каждый файл отвечает за один пользовательский сценарий и связывает форму/данные/отображение. Загрузка отменяется при смене фильтров; значения с отсутствием данных не подменяются нулями.

## Как здесь идёт работа

`Forecast` получает профиль из capabilities, ставит задание, ждёт его завершения и показывает точки. `History` получает наблюдения; `Evaluations` читает уже опубликованный отчёт, а не запускает обучение. `Occupancy` отправляет план/следующую остановку и показывает сохранённое состояние; `Fleet` считает отдельный сценарий через API. `Context` получает снимки внешних источников и их статус — наличие снимка не означает, что текущая база использовала его в прогнозе.

Входы экранов — общий API-клиент, выбранная ревизия/маршрут и пользовательские параметры; выходы — команды API и визуальное представление результата. Следующая работа после подключения модели: показать фактическую версию/метод, корректное сравнение кандидата с базой, ограничения меток. Форму «обучить модель» без backend-процесса добавлять не нужно. Проверять смену фильтров во время запроса, пустую выдачу и ошибки источника.

## Файлы

| Файл                               | Назначение                                                                                              |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------- |
| [Context.jsx](Context.jsx)         | Получение/просмотр погодных и событийных снимков, состояния источников, геообъекты и атрибуция.         |
| [Evaluations.jsx](Evaluations.jsx) | Отчёты, folds, all/peak метрики и сравнение факта с сезонной базой.                                     |
| [Fleet.jsx](Fleet.jsx)             | Форма сценария выпуска с целевым заполнением, оборотом и резервом.                                      |
| [Forecast.jsx](Forecast.jsx)       | Профили/границы дат, создание запуска, polling, сохранённые результаты, единые фильтры карты и графика. |
| [History.jsx](History.jsx)         | Выбор профиля и периода наблюдений, пространственный ряд, график и CSV.                                 |
| [Occupancy.jsx](Occupancy.jsx)     | Создание ручного рейса, очередная остановка, измеренные высадки и таблица сохранённого баланса.         |
