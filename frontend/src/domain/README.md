# Преобразования представления (frontend/src/domain)

Чистые функции форматирования и подготовки данных для отображения, графиков и карты. Они не обращаются к сети и не управляют React-состоянием.

---

## Файлы

| Файл                         | Назначение                                                                                                          |
| ---------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| [aggregate.js](aggregate.js) | Поля периода на сетке профиля, допустимые группировки и подписи остановок/участков.                                 |
| [format.js](format.js)       | Формат времени/чисел, подписи, идентичность ряда, CSV-экранирование и разрывы линий на пропусках.                   |
| [mapStyle.js](mapStyle.js)   | Расчет цветовой гаммы сегментов трамвайных путей на карте в зависимости от пассажиропотока и коэффициента загрузки. |
