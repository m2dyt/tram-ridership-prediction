# Преобразования представления (frontend/src/domain)

Чистые функции форматирования и подготовки данных для отображения, графиков и карты. Они не обращаются к сети и не управляют React-состоянием.

---

## Файлы

| Файл                                       | Назначение                                                                                                          |
| ------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| [aggregate.js](aggregate.js)               | Поля периода на сетке профиля, допустимые группировки и подписи остановок/участков.                                 |
| [format.js](format.js)                     | Формат времени/чисел, подписи, идентичность ряда, CSV-экранирование и разрывы линий на пропусках.                   |
| [mapStyle.js](mapStyle.js)                 | Расчет цветовой гаммы сегментов трамвайных путей на карте в зависимости от пассажиропотока и коэффициента загрузки. |
| [dashboardData.js](dashboardData.js)       | Подбор профиля и периода наблюдений, подсчёт маршрутов с доступным прогнозом.                                       |
| [evaluation.js](evaluation.js)             | Подписи метода и статуса исторической оценки.                                                                       |
| [evaluationScores.js](evaluationScores.js) | Представление оценок по методам, маршрутам и часам пик.                                                             |
| [forecast.js](forecast.js)                 | Проверка параметров расчёта и подписи методов и ограничений прогноза.                                               |
| [historyWindow.js](historyWindow.js)       | Начальный диапазон истории с учётом доступного периода и шага наблюдений.                                           |
| [mapDemand.js](mapDemand.js)               | План почасовых расчётов по датам и уровни спроса относительно среднего за день.                                     |
| [mapBounds.js](mapBounds.js)               | Границы GeoJSON-объектов, чтобы карта прогноза показывала выбранный маршрут целиком.                                |
