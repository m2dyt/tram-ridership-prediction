# Преобразования представления

Чистые функции форматирования и подготовки графика/CSV. Они не обращаются к сети и не управляют React-состоянием.

## Файлы

| Файл                         | Назначение                                                                                                              |
| ---------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| [format.js](format.js)       | Формат времени/чисел, подписи, идентичность ряда, CSV-экранирование и разрывы линии на пропусках.                       |
| [aggregate.js](aggregate.js) | Поля периода на сетке профиля (включительный конец → исключающий), допустимые группировки и подписи остановок/участков. |
