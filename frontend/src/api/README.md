# Клиент API (frontend/src/api)

Все запросы идут по относительному пути `/api/v1`. Нет обращения к PostgreSQL или напрямую к ключевым сервисам погоды.

---

## Файлы

| Файл                                       | Назначение                                                                               |
| ------------------------------------------ | ---------------------------------------------------------------------------------------- |
| [apiFetch.js](apiFetch.js)                 | Базовая обертка над fetch с поддержкой перехвата ответов, cookies и токенов.             |
| [client.js](client.js)                     | Fetch-клиент, Bearer авторизация, отмена запросов, API-ошибки и пагинация.               |
| [hooks.js](hooks.js)                       | Реэкспорт основных хуков взаимодействия с бэкендом.                                      |
| [tokenBus.js](tokenBus.js)                 | Шина событий и реактивного обновления токенов авторизации.                               |
| [modelCatalog.js](modelCatalog.js)         | Чтение списка моделей и предупреждения об активной версии.                               |
| [observationPages.js](observationPages.js) | Полная загрузка страниц наблюдений, прогнозов и отчётов с защитой от повторного курсора. |
