# Общие компоненты

Переиспользуемые элементы интерфейса. Карта/график получают подготовленные данные; не выбирают самостоятельно dataset/run.

## Файлы

| Файл                     | Назначение                                                                                               |
| ------------------------ | -------------------------------------------------------------------------------------------------------- |
| [Chart.jsx](Chart.jsx)   | SVG-график, выбор интервала карты и доступная таблица значений.                                          |
| [Common.jsx](Common.jsx) | Отменяемая загрузка ресурсов, состояния ошибки/пустоты, Badge, CSV-загрузка и безопасные внешние ссылки. |
| [Map.jsx](Map.jsx)       | Жизненный цикл Leaflet, OSM с атрибуцией, геометрии/попапы без HTML-инъекций и слои контекста.           |
