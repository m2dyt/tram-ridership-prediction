# Интерфейс

App управляет подключением, выбранной сетью/маршрутом и навигацией. Экраны из features используют единый клиент api; components переиспользуются. Расчёт пассажирской массы выполняется backend, а не дублируется в React.

## Файлы

| Файл                     | Назначение                                                                                    |
| ------------------------ | --------------------------------------------------------------------------------------------- |
| [App.jsx](App.jsx)       | Вход с ключом в памяти, навигация, версия набора/сети, выбор маршрута и переключение экранов. |
| [main.jsx](main.jsx)     | Монтирование React StrictMode и подключение стилей приложения/Leaflet.                        |
| [styles.css](styles.css) | Система цветов/типографики, сетки, карта, таблицы и адаптивная верстка.                       |
