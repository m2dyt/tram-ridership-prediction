# Frontend

React 19 на JavaScript/JSX, Vite 8, Leaflet/OSM. Node 22.12+ в ветке 22 либо 24+.

Команды ниже выполняются **из этой папки** (`cd frontend` из корня). API и worker запускаются из корня проекта отдельно.

```powershell
npm.cmd ci
npm.cmd run dev
```

API-прокси по умолчанию: 127.0.0.1:8000; интерфейс: 127.0.0.1:5173. `npm run build` создаёт dist, который раздаёт FastAPI при следующем запуске. `npm run test`, `npm run format:check` — проверки. Ключ API вводится в интерфейсе и хранится только в памяти. Не добавлять секреты поставщиков в VITE_* или исходники. OSM-тайлы требуют атрибуции и доступа к сети; bulk/offline скачивание не выполняется.

## Что происходит с данными

После входа приложение получает capabilities и сеть. Пользователь выбирает доступный профиль и маршрут. Экран прогноза создаёт задание, опрашивает его состояние и загружает сохранённые точки; график и карта используют один run_id и фильтр. История получает наблюдения, оценка — опубликованные отчёты, форма рейса — сохранённый баланс. React не вычисляет высадки и не обучает модель.

`src/api` отвечает за HTTP и пагинацию; `src/features` — пользовательские сценарии; `src/components` — карту/график и общие состояния; `src/domain` — преобразование данных для отображения. Вход — контракт API; выход — интерфейс и пользовательские команды API, а не файлы обучения.

## Что менять после появления реальных данных и модели

Проверить отображение реальной сети, качества/происхождения данных и доступных профилей. После расширения backend проверить название и версию модели, прогноз/факт, независимое сравнение с базой и отсутствие данных. Не показывать «обученная модель», пока такой метод реально не выбран backend. При новом квартальном профиле потребуются согласованные календарные подписи/границы и контракт; просто переименовать месячный график недостаточно.

Ревью: единые фильтры карты/графика, обработка загрузки/ошибки/пропусков, отсутствие секретов и вычислений предметной модели в UI. Запустить `npm.cmd run test`, `npm.cmd run build`, `npm.cmd run format:check`; ручной сценарий — [TESTING.md](../docs/TESTING.md).
