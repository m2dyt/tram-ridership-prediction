# Тесты frontend (frontend/tests)

Встроенный node:test, без внешних браузерных зависимостей: `npm run test`. Инструкции описаны в [TESTING.md](../../docs/TESTING.md).

---

## Файлы

| Файл                                                   | Назначение                                                                    |
| ------------------------------------------------------ | ----------------------------------------------------------------------------- |
| [aggregate.test.js](aggregate.test.js)                 | Тесты полей периода агрегации, допустимых группировок и подписей групп.       |
| [client.test.js](client.test.js)                       | Тесты пагинации, авторизации/ошибок, пропусков, времени и CSV.                |
| [map-style.test.js](map-style.test.js)                 | Тесты стилизации карты: расчет цвета и толщины полилиний по уровням загрузки. |
| [dashboard-data.test.js](dashboard-data.test.js)       | Проверки выбора профилей, диапазонов наблюдений и подсчёта маршрутов.         |
| [evaluation-scores.test.js](evaluation-scores.test.js) | Проверки оценок по методам и маршрутам и правила пика из отчёта.              |
| [evaluation.test.js](evaluation.test.js)               | Проверки подписей метода и статуса оценки.                                    |
| [forecast.test.js](forecast.test.js)                   | Проверки параметров расчёта, подписей моделей и выгрузки итогов.              |
| [history-window.test.js](history-window.test.js)       | Проверки границ истории, календарных месяцев и високосного года.              |
| [map-demand.test.js](map-demand.test.js)               | Проверки выбора маршрутов для почасовых расчётов и классификации спроса.      |
| [model-catalog.test.js](model-catalog.test.js)         | Проверки предупреждений о состоянии активной версии модели.                   |
| [observations.test.js](observations.test.js)           | Проверки пагинации наблюдений, точек оценки и других списков.                 |
| [map-bounds.test.js](map-bounds.test.js)               | Проверки границ линий и остановок маршрута для карты прогноза.                |
