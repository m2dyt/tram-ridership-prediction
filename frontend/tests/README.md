# Тесты frontend (frontend/tests)

Встроенный node:test, без внешних браузерных зависимостей: `npm run test`. Инструкции описаны в [TESTING.md](../../docs/TESTING.md).

---

## Файлы

| Файл                                   | Назначение                                                                    |
| -------------------------------------- | ----------------------------------------------------------------------------- |
| [aggregate.test.js](aggregate.test.js) | Тесты полей периода агрегации, допустимых группировок и подписей групп.       |
| [client.test.js](client.test.js)       | Тесты пагинации, авторизации/ошибок, пропусков, времени и CSV.                |
| [map-style.test.js](map-style.test.js) | Тесты стилизации карты: расчет цвета и толщины полилиний по уровням загрузки. |
