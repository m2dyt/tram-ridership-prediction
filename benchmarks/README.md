# Результаты бенчмарков производительности

Каталог для сохранения отчётов замера производительности инференса, задержек и пропускной способности моделей трамвайного прогнозирования.

## Запуск бенчмарка

```powershell
python scripts/benchmark_inference.py --iterations 10
```

## Файлы

| Файл | Назначение |
|---|---|
| [latest.json](latest.json) | Последний сформированный отчёт бенчмарка инференса с квантилями задержки (p50, p90, p95, p99), RPS и памятью. |
