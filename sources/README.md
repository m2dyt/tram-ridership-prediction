# sources — оригиналы внешних данных

Здесь начинается путь от датасета к модели. В этой папке лежат **неизменённые файлы поставщиков**, а не очищенные таблицы и не веса модели. Содержимое исключено из Git, кроме этого README. После клонирования локальных выгрузок здесь не будет; их получают по [реестру источников](../docs/DATASETS.md).

## Что делать в этой папке

1. Получить официальную выгрузку по [инструкции для 624/62743](../docs/DATASETS.md). Создать каталог `data-mos/<id>/<дата-получения>/` и сохранить исходное имя/расширение файла.
2. Рядом сохранить `provenance.json`: `provider`, `dataset_id`, `source_url`, `source_version`, `retrieved_at`, `published_at`, `content_sha256`, `raw_file`, `license_url`, `attribution`, `coverage`, `quality_notes`. Это предлагаемый паспорт файлового архива; текущий importer не читает его автоматически.
3. Если время публикации неизвестно, записать `published_at: null`. Не подставлять дату события. Зафиксировать первое достоверное получение; для исторического backtesting отдельно доказать более раннюю доступность данных.
4. Словарь полей и исходный паспорт поставщика сохранить рядом. Ключи доступа, авторизационные заголовки и URL с секретом в паспорт не включать.
5. Преобразование запускать в новый каталог [data](../data/README.md). Оригиналы не исправлять и не перезаписывать при нормализации.

Получить контрольную сумму в PowerShell можно через `Get-FileHash -Algorithm SHA256 -LiteralPath <путь-к-выгрузке>`; вместо шаблона подставить фактический файл. Команды обработки выполняются из корня проекта с активной `.venv`.

## Что выходит из этой папки

Вход для следующего этапа — исходный файл + паспорт + словарь полей. После обработки они остаются здесь; производные CSV/GeoJSON и отчёт качества появляются в `data/`. При каждом изменении поставщика создаётся новая версия с новым хешем. Текущий `context-refresh` сохраняет нормализованные снимки в БД и **не архивирует автоматически** сырые HTTP-ответы в эту папку.

## Ревью перед подготовкой данных

Файл открывается в заявленном формате; ID и название набора совпадают с карточкой; единицы и покрытие известны; время и хеш зафиксированы; права использования прочитаны; секретов нет. HTTP 200 HTML-страницы не принимается за выгрузку JSON. Следующий шаг: [data/README.md](../data/README.md).
