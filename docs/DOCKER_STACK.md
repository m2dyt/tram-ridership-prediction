# Полный запуск через Docker

Из корня репозитория выполни `sh scripts/start-stack.sh`. Перед запуском должен работать Docker Desktop, а архив конкурса должен лежать в `dataset/` с файлами меток в подпапке `labels/`.

Сценарий создаёт `.env`, если его нет, запускает PostgreSQL, выполняет миграции, проверяет общую учётную запись оператора, публикует реальную маршрутную сеть и почасовые метки, затем обучает модель HistGradientBoosting на CPU. Контейнер API отдаёт собранный интерфейс и REST API; отдельный worker обрабатывает запросы прогнозирования. Данные PostgreSQL и модель хранятся в именованных томах Docker.

## Общий оператор

Открой `http://localhost:8000` и войди общей учётной записью оператора — она одинакова у всех установок:

| Логин | Пароль |
|---|---|
| `operator` | `Tram-Operator-2025` |

Учётную запись создаёт миграция `0006_shared_operator`, а `scripts/bootstrap-operator.py` при каждом `start-stack.sh` восстанавливает её, если её удалили, понизили до просмотра, отключили или сменили пароль. В коде хранится только argon2-хеш (`backend/src/tram/infrastructure/shared_operator.py`). Это учётная запись для локального стенда: API в Docker слушает только `127.0.0.1`. Перед публичным развёртыванием замените пароль (новый хеш в `shared_operator.py` и новая миграция) или удалите учётную запись.

Регистрация через интерфейс создаёт пользователя с ролью просмотра; оператор нужен для запуска прогнозов и других команд записи.

После запуска скрипт печатает статусы контейнеров и количество строк в `dataset_revisions`, `network_revisions`, `series`, `observations` и `users`. API доступен по `http://localhost:8000/api/v1`, Swagger UI — `http://localhost:8000/docs`, PostgreSQL слушает только `127.0.0.1:15433`.

Повторный запуск безопасен: публикация использует ревизию по хешу файлов меток, импорт пропускает уже существующую версию, а обучение повторно использует бандл для того же хеша меток.

Полезные команды:

```sh
docker compose ps
docker compose logs -f api worker
docker compose exec -T db psql -U tram -d tram -c 'select count(*) from observations'
docker compose down
```

`docker compose down` останавливает контейнеры и сохраняет именованные тома. Для смены каталога данных задай `TRAM_DATASET_PATH` перед запуском скрипта.
