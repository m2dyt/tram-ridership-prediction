# Документация проекта

Начать с [корневого README](../README.md). Для следующего этапа читать **DATASETS → README папок sources/data → TRAINING_PLAN → README папок ml/models**. Для запуска — OPERATIONS, для изменения кода — ARCHITECTURE, для проверки — TESTING. STATUS фиксирует реальные границы готовности; IMPLEMENTATION_LOG — историю шагов и ревью.

## Что хранится именно здесь

Это общие правила и решения, которые затрагивают несколько компонентов: временной контракт, происхождение данных, план обучения, сценарии запуска и критерии качества. Описание конкретной функции/файла находится в README её папки; исходные выгрузки — в `sources/`, результаты — в `data/` и `models/`. В этой папке нет обученного датасета или скрытого процесса `fit`.

После каждого изменения обновлять инструкцию соответствующего сценария и фактический статус. Новые ссылки проверять содержательно: HTML портала и файл датасета — разные результаты. Сетевая проверка фиксируется в DATA_LINK_CHECKS.json, а локальная навигация проверяется `python scripts/check_docs.py`. Будущие артефакты и команды помечать как план; не добавлять их в список реализованных возможностей.
