# Документация проекта

Начать с [глобального плана проекта](../00_ГЛОБАЛЬНЫЙ_ПЛАН_К_ЭТАЛОНУ.md), который находится в корне репозитория. Далее использовать этот каталог как справочник: DATASETS/DATA_AUDIT — данные; README конкретных папок — назначение модулей; OPERATIONS — запуск; ARCHITECTURE — границы кода; TESTING — проверки. STATUS фиксирует состояние, IMPLEMENTATION_LOG — историю сделанных шагов.

## Что хранится именно здесь

Это справочные документы, стандарты и результаты, которые затрагивают несколько компонентов. Глобальный порядок работ ведётся только в [корневом плане проекта](../00_ГЛОБАЛЬНЫЙ_ПЛАН_К_ЭТАЛОНУ.md). Описание конкретной функции/файла находится в README её папки; исходные выгрузки — в `sources/`, результаты — в `data/` и `models/`.

После каждого изменения обновлять инструкцию соответствующего сценария и фактический статус. Новые ссылки проверять содержательно: HTML портала и файл датасета — разные результаты. Сетевая проверка фиксируется в DATA_LINK_CHECKS.json, а локальная навигация проверяется `python scripts/check_docs.py`. Будущие артефакты и команды помечать как план; не добавлять их в список реализованных возможностей.
