- KudaGo: адаптер проверен на ответах-фикстурах; после первоначального ConnectTimeout повторный прямой запрос вернул HTTP 200. Сохранён образец 5 событий первой страницы, полный каталог не загружен.
- Timepad: анонимный живой запрос вернул 403. Параметр токена предусмотрен; действующий токен не предоставлен.
- WeatherAPI: адаптер/обработка ошибок проверены на фикстурах; действующий ключ не предоставлен.
- data.mos.ru: наборы 624/62743 из спецификации пользователя скачаны через браузерный экспорт, вместе с паспортами: 1 177 и 6 448 записей. Прямой HTTP возвращал HTML-оболочку, API — 401 с требованием api_key.
- OSM/Geofabrik: официальная страница выгрузки Центрального ФО прочитана исследовательским инструментом; локальный запрос завершился таймаутом. Полный архив не скачивался и в сеть проекта не импортирован.

## Эксплуатационные границы

Локальный запуск: API/worker в .venv + PostgreSQL в Docker. SQLite — тестовый режим. Bearer viewer/operator подходят для закрытого прототипа; для внешнего размещения нужны HTTPS, управление пользователями и секретами, наблюдаемость, резервное копирование, защита периметра и проверка лимитов нагрузки. Ключи не встраиваются во frontend.

Размер HTTP-команды ограничен 64 KiB, ответа провайдера — 5 MB, GeoJSON — 50 MB. История/точки запрашиваются окнами до 366 дней. Внешние запросы выполняются по явному действию; автоматический планировщик/бесконечные повторы не запускаются. Каталоги мероприятий ограничены 100 событиями за запрос и не являются полным перечнем событий города.

Python-зависимости заданы совместимыми диапазонами в pyproject/единственном requirements.txt; это не полный транзитивный lock. npm использует точные версии и package-lock.json. Известны два предупреждения об устаревающих интерфейсах зависимостей FastAPI/TestClient; тесты проходят, несовместимых пакетов pip check не обнаруживает.

Dockerfile включает frontend и backend. Предыдущая и итоговая доступность контейнерной сборки фиксируется в [журнале проверок](IMPLEMENTATION_LOG.md); наличие Dockerfile само по себе не означает успешную сборку в закрытой сети.
