# Backend

FastAPI, сценарии приложения и PostgreSQL. Запуск из корня: `python -m tram.cli serve`; отдельно `python -m tram.cli worker`. Миграции: `python -m tram.cli migrate`. [Устройство решения](../docs/ARCHITECTURE.md).
