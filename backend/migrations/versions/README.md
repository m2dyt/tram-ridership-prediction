# Версии схемы

Порядок 0001 → 0002 → 0003 → 0004 → 0005. Тесты проверяют upgrade/downgrade и соответствие ORM. Downgrade предназначен для контролируемой миграции и может удалять таблицы; в обычном запуске применяется только upgrade.

## Файлы

| Файл | Назначение |
|---|---|
| [0001_initial.py](0001_initial.py) | Начальная схема версий, наблюдений, очереди, прогнозных точек и отчётов оценки. |
| [0002_run_status_times.py](0002_run_status_times.py) | Время переходов состояния очереди для стабильной пагинации. |
| [0003_persist_trip_balance_and_context_.py](0003_persist_trip_balance_and_context_.py) | Таблицы рейсов, событий/checkpoints и внешних снимков; ограничения и индексы. |
| [0004_auth.py](0004_auth.py) | Пользователи и refresh-сессии. |
| [0005_login_attempts.py](0005_login_attempts.py) | Счётчики попыток входа и индекс для удаления истёкших окон. |
