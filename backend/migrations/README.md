# Миграции

Запускать из корня через `python -m tram.cli migrate`. Не редактировать уже применённые миграции ради нового изменения; создать следующую версию. Устаревшие пользовательские типы не импортируются в миграции — схема зафиксирована явно.

## Файлы

| Файл | Назначение |
|---|---|
| [env.py](env.py) | Окружение Alembic: metadata приложения, секретный URL из настроек, online/offline миграции. |
| [script.py.mako](script.py.mako) | Шаблон новой миграции; не исполняется при обычном запуске. |
