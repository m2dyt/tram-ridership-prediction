# Сценарии приложения

Оркестрация через внедрённые порты. Не импортировать infrastructure, FastAPI, SQLAlchemy или tram_ml. Реализации подключаются в composition.py.

## Как проходят сценарии

Публикация получает документы manifest и поток наблюдений, проверяет связи/профили/временную сетку, затем передаёт их writer. Прогноз сначала проверяется в `service.py` и сохраняется заданием; `worker.py` отдельно захватывает его с lease, читает разрешённую историю, вызывает `Predictor` и атомарно завершает результат. Эти шаги не смешиваются с разбором HTTP или устройством SQL-таблиц.

Рейс проходит через `occupancy.py`: план/событие → проверка сети, порядка, времени и повторов → domain-баланс → порт хранения. `occupancy_export.py` превращает завершённые проезды в агрегаты истории; он не придумывает измеренные высадки. `context.py` сохраняет результат получения внешнего источника и время доступности, но не выбирает HTTP-библиотеку.

## Следующее изменение и ревью

Для нового источника либо модели сначала описать необходимый порт/документ, затем сценарий с внедрённой реализацией. `Predictor` сейчас не принимает отдельный контекст признаков — это надо спроектировать до подключения модели с погодой. Для кандидата расширить выбор методов в `publication/service/worker` и раздельное сравнение в `evaluation`. На ревью проверить границы `as_of`, разрешённые версии, идемпотентность и поведение при отсутствии данных. [План обучения](../../../../docs/TRAINING_PLAN.md).

## Файлы

| Файл | Назначение |
|---|---|
| [__init__.py](__init__.py) | Маркер Python-пакета; не открывает БД, сеть и не запускает процессы при импорте. |
| [context.py](context.py) | Порты источника/снимков и сценарий сохранения полученного контекста с available_at. |
| [errors.py](errors.py) | Ошибки сценариев с кодами для HTTP/CLI. |
| [evaluation.py](evaluation.py) | Оркестрация полных временных folds, прогноз/факт, срезы метрик и публикация отчёта через порты. |
| [mapping.py](mapping.py) | Преобразование JSON пространственных ключей в domain-типы и обратно. |
| [occupancy.py](occupancy.py) | Сценарии создания/чтения рейса, проверки сети и доступности события, идемпотентные fingerprint. |
| [occupancy_export.py](occupancy_export.py) | Построение проездов по участкам из журналов и prepared bundle восстановленной наполненности. |
| [ports.py](ports.py) | Протоколы repository, clock, cursor, predictor и документы границ. |
| [publication.py](publication.py) | Семантическая проверка сети, профилей, моделей, временной сетки и полного потока наблюдений. |
| [service.py](service.py) | Чтение каталогов/истории/результатов/оценок, фильтры и курсоры; создание прогнозных запусков. |
| [worker.py](worker.py) | Получение задания с lease, чтение разрешённой истории, вызов предиктора и атомарная публикация результата. |
