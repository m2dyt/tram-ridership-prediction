# Предметная область

Чистые функции и типы, стандартная библиотека. Здесь нет SQL, HTTP, .env и обучения. Изменение расчёта требует проверки инвариантов времени и сохранения массы.

## Какие расчёты выполняются здесь

Для события остановки `occupancy.py` получает состояние групп пассажиров и входы/выходы. Выдаёт следующее состояние: невышедшие группы остаются в вагоне, новые добавляются, конечная очищает остаток по правилам плана. Исходный объект не заменяется SQL-записью внутри формулы — сохранение делает внешний сценарий.

`aggregation.py` получает завершённые проезды и их длительности: результат — взвешенная наполненность/доля вместимости. `fleet.py` получает спрос, вместимость, целевое заполнение, оборот и резерв: результат — сценарный интервал, требуемое число вагонов и дефицит. `time.py` и `series.py` не дают смешать неверные временные сетки и показатели.

## Следующий шаг и ревью

Для новых измерений сначала уточнить физический смысл и единицы. Квартальное метро имеет отдельные типы `Quarter`, `QuarterlyPoint` и `QuarterSplit` в `metro.py`; сетка HTTP API остаётся hour/day/month. Если кварталы понадобятся в приложении, потребуется согласованное расширение контракта, публикации и прогнозирования. При изменении баланса проверять неотрицательность, перенос остатка, конечную и сохранение массы. Чтение датасетов, обучающей библиотеки и файлов модели остаётся за пределами domain.

## Файлы

| Файл | Назначение |
|---|---|
| [__init__.py](__init__.py) | Маркер Python-пакета; не открывает БД, сеть и не запускает процессы при импорте. |
| [aggregation.py](aggregation.py) | Среднее по длительности проездов, отдельная нормализация на вместимость каждого вагона. |
| [errors.py](errors.py) | Предметная ошибка нарушения инварианта. |
| [fleet.py](fleet.py) | Сценарный расчёт числа вагонов, интервала движения и дефицита резерва без оптимизации. |
| [metro.py](metro.py) | Типы отдельного квартального эксперимента, ID пары станция/линия, значения и временные splits. |
| [occupancy.py](occupancy.py) | Распределение групп по остановкам, баланс массы, измеренные высадки, конечная и переполнение. |
| [series.py](series.py) | Показатели, пространственные ключи, наблюдения и прогнозные точки; проверки значений. |
| [time.py](time.py) | UTC/Moscow, RFC3339, интервалы, календарные горизонты и допустимые временные сетки. |
