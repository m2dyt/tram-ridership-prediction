# Предметная область

Чистые функции и типы, стандартная библиотека. Здесь нет SQL, HTTP, .env и обучения. Изменение расчёта требует проверки инвариантов времени и сохранения массы.

## Файлы

| Файл | Назначение |
|---|---|
| [__init__.py](__init__.py) | Маркер Python-пакета; не открывает БД, сеть и не запускает процессы при импорте. |
| [aggregation.py](aggregation.py) | Среднее по длительности проездов, отдельная нормализация на вместимость каждого вагона. |
| [errors.py](errors.py) | Предметная ошибка нарушения инварианта. |
| [fleet.py](fleet.py) | Сценарный расчёт числа вагонов, интервала движения и дефицита резерва без оптимизации. |
| [occupancy.py](occupancy.py) | Распределение групп по остановкам, баланс массы, измеренные высадки, конечная и переполнение. |
| [series.py](series.py) | Показатели, пространственные ключи, наблюдения и прогнозные точки; проверки значений. |
| [time.py](time.py) | UTC/Moscow, RFC3339, интервалы, календарные горизонты и допустимые временные сетки. |
