# HTTP API

Исполняемый контракт — [openapi.yaml](../../../../openapi.yaml), Swagger — `/docs`, базовый путь — `/api/v1`. Защищённые GET требуют viewer/operator, защищённые POST — operator; публичные операции перечислены в OpenAPI. Новая операция добавляется одновременно в контракт, binding и тест ответа.

## Что делает HTTP-слой

Вход — HTTP-параметры, JSON и Bearer-токен. `app.py` проверяет роль, размер/структуру тела и контракт; вызывает сценарий через binding. Выход — документ по OpenAPI либо стандартная ошибка. `extensions.py` подключает рейсы, снимки контекста и калькулятор к их сценариям. Формулы, обучение и SQL-запросы в обработчиках не размещаются.

`POST /auth/login` передаёт сервису адрес клиента из ASGI-соединения. После пяти неудачных попыток для пары логин + IP за 15 минут сервис возвращает `429 RATE_LIMITED`; `app.py` добавляет `Retry-After` в секундах. Заголовок `X-Forwarded-For` обработчик напрямую не читает.

POST прогноза возвращает задание; вычисление происходит в отдельном worker. Swagger описывает реально подключённые операции, а не будущий CLI обучения. При добавлении метода модели проверить его метаданные, совместимость профиля и отчёты; новый endpoint нужен только если существующий контракт не выражает сценарий. Проверка: `tests/test_api.py` и startup-сверка operationId с обработчиками.

## Файлы

| Файл | Назначение |
|---|---|
| [__init__.py](__init__.py) | Маркер Python-пакета; не открывает БД, сеть и не запускает процессы при импорте. |
| [app.py](app.py) | HTTP-адаптер: Bearer-роли, строгий JSON, JSON Schema, параметры, ошибки, CORS и маршруты из OpenAPI. |
| [extensions.py](extensions.py) | Привязка операций рейсов, контекста и калькулятора к сервисам и чистым функциям. |
