# ml/experiments — конфигурации экспериментов обучения

Файлы конфигураций задают временные сплиты, списки признаков, случайные сиды и гиперпараметры моделей.

## Файлы конфигураций

| Файл | Описание |
|---|---|
| [metro_ridge_v1.json](metro_ridge_v1.json) | Конфигурация $L_2$-регуляризованной линейной регрессии (Ridge) на сезонных лагах и категориях линий. |
| [metro_gbdt_v1.json](metro_gbdt_v1.json) | Конфигурация градиентного бустинга деревьев решений (HistGradientBoosting) на сезонных лагах и календаре. |
