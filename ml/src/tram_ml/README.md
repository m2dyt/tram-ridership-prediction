# Библиотека tram_ml

Зависимости: стандартная библиотека и tram.domain. Внешний HTTP/SQL и обучение запрещены в текущем объёме. Сезонная база не использует погодные признаки — они подготовлены для будущего этапа.

## Входы, обработка и результат

`baseline.py` принимает историю `Observation`, список пространственных рядов, окно, горизонт, разрешение и `as_of`. Отбрасывает незавершённые/недоступные наблюдения, проверяет совпадение сетки и дубли, выбирает опорный сезонный интервал. Возвращает `tuple[Prediction, ...]`; отсутствие опоры остаётся объяснённым `null`.

`features.py` переводит timestamp в календарь Москвы. Флаг выходного сейчас учитывает только субботу/воскресенье. `context.py` получает уже загруженные снимки, проверяет доступность на отсечке и пространственную близость; он не обращается к погодным сайтам. `evaluation.py` задаёт полные временные окна и оценивает сопоставимые факты/прогнозы. БД и публикация отчётов находятся в backend, не здесь.

## Как менять эту папку

Изменение формулы сопровождается проверкой границ времени, пропусков и единиц в `tests/test_domain_ml.py` / `tests/test_context.py`. Новые признаки должны вычисляться одинаково для обучения и выдачи прогноза. Загрузчик файлов модели и сетевые клиенты сюда не помещать. Следующая задача — описать набор доступных признаков для выбранного целевого ряда; будущий процесс `fit` размещается отдельно по [плану обучения](../../../docs/TRAINING_PLAN.md).

## Файлы

| Файл | Назначение |
|---|---|
| [__init__.py](__init__.py) | Маркер Python-пакета; не открывает БД, сеть и не запускает процессы при импорте. |
| [baseline.py](baseline.py) | SeasonalNaive: предыдущая доступная неделя/год, без fit и без использования будущих наблюдений. |
| [context.py](context.py) | Расстояния и сопоставление внешних снимков по месту, времени и доступности на as_of. |
| [evaluation.py](evaluation.py) | Полные временные folds и MAE/WAPE с объяснимыми пустыми/нулевыми случаями. |
| [features.py](features.py) | Календарные признаки Москвы: час, день недели, месяц, выходной. |
