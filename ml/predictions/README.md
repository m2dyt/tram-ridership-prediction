# ml/predictions — выходные прогнозы

`submission.csv` — текущий отслеживаемый конкурсный CSV: `route;date;hour;prediction`, 14 640 data rows. Он соответствует форме route/date/hour из трамвайного скрипта, но сам по себе не доказывает, что сгенерирован текущим кодом/данными, совпадает с точным test sample или был принят площадкой.

Перед созданием нового файла сохрани лучший ранее отправленный вариант отдельно, затем сравни keys/порядок с `test_submission.csv`, проверь уникальность, пропуски, неотрицательность и обязательный маршрут 5. Записывай вместе с результатом ID модели, input hashes, config, split и метрики. Не помещай сюда сырые test targets.

Порядок генерации и review описан в [инструкции тренера](../training/README_TRAM_TRAINING.md), а полный маршрут проекта — в [глобальном плане](../../00_ГЛОБАЛЬНЫЙ_ПЛАН_К_ЭТАЛОНУ.md).
