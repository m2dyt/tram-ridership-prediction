# Локальные данные конкурса

Распакуй `dataset.zip` непосредственно в этот каталог. Не помещай файлы в дополнительную вложенную папку с именем архива.

Ожидаемая структура:

```text
dataset/
├── labels/
│   ├── labels_day_train.csv
│   └── labels_day_test.csv
├── spravochniki/
│   ├── Хакатон_пример_валидаций.xlsx
│   └── Хакатон_справочники_трамвай_10_маршрутов.xlsx
├── test.csv
├── test_submission.csv
├── train.csv
└── README.md
```

`scripts/build_competition_bundle.py` публикует почасовые агрегаты из `labels/` в PostgreSQL. Скрипт обучения использует те же метки и `test_submission.csv`; необработанные `train.csv` и `test.csv` сохраняются как оригинальные файлы конкурса и не загружаются в базу.

Исходные данные исключены из Git из-за размера. Этот файл описывает структуру, а файлы архива остаются локальными.
